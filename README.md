#plantEvo viewer

Site web statique qui présente l'évolution des végétaux des six grands groupes.

##A propos

PlantEvo viewer invite le visiteur à voyager dans l'histoire des plantes. Depuis la page d'accueil, il choisit un groupe de végétaux et découvre comment les plantes ont évolué pour conquérir la terre ferme.

Objectifs du projet :
-Mettre en pratique le HTML5 et le CSS3 sur un projet complet
-Structurer un site multi-pages avec une arborescence claire
-Soigner la lisibilité, la cohérence visuelle et l'organisation du code

##Les six groupes présentés

| Ordre | Groupe |
| 1 | Algues |
| 2 | Mousses |
| 3 | Fougères |
| 4 | Conifères |
| 5 | Graminées |
| 6 | Dicotylédones |
